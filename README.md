## Description
A full-stack app for ordering Bhutanese dishes with user login, Stripe payments and an admin dashboard for menu and order management.
<img width="1551" height="901" alt="image" src="https://github.com/user-attachments/assets/5d9771cd-e678-4b71-aa25-e462c1109f55" />

## Features
### User
- Registration and login
- Various food categories
- Add items to cart and update quantities
- Stripe payment gateway
- Order tracking

### Admin
- Manage menu items (add/delete)
- Manage orders (view/update)
